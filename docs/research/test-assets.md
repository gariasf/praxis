# Test models and resources: sources, licenses, fit

Researched 2026-10-12 against each source's own pages. Licenses are quoted as the source states them. "Unverified" marks claims the source page did not confirm. For Khronos models the authority is the repo's machine-readable [`REUSE.toml`](https://github.com/KhronosGroup/glTF-Sample-Assets/blob/edc7c9e67c639d230715049ee31f9a96a6babbbe/REUSE.toml) (`precedence = "aggregate"`), whose model tables state the licences the per-model READMEs give [ref:khronos-sample-assets-reuse]. Audited 2026-10-26 at the commit the manifest pins: each model's table is keyed `Models/<name>/*`, and REUSE's `*` stops at a path separator while only the last matching table applies [ref:reuse-3.3-globbing], so read strictly the model files in subfolders (`glTF/`, `glTF-Binary/`) fall to the catch-all `**` table, `CC-BY-4.0` © 2017-2026 Khronos Group. Every model table has the same form, so this reads as a slip in the globs rather than a licence; the model's own README states its licence ([ref:scifihelmet-readme-legal], [ref:normaltangenttest-readme-legal]) and decides it here, and `assets/ATTRIBUTION.md` also gives the credit the strict reading would require.

## Reference tools (independent oracles)

- [glTF-IBL-Sampler](https://github.com/KhronosGroup/glTF-IBL-Sampler) [ref:gltf-ibl-sampler], Apache-2.0 [ref:gltf-ibl-sampler-license]: HDR panorama in; Lambertian diffuse cube map, GGX specular cube map with mips, and BRDF LUT out. Its KTX2 output can be basis-compressed (lossy); compare against an uncompressed format and match sample count, resolution, and LOD bias.
- [glTF-Sample-Renderer](https://github.com/KhronosGroup/glTF-Sample-Renderer) [ref:gltf-sample-renderer], Apache-2.0 [ref:gltf-sample-renderer-license]: Khronos' official WebGL2 renderer, used in Google's Render Fidelity Tools. No headless mode documented; a headless browser would drive it (unverified).
- [glTF-Asset-Generator](https://github.com/KhronosGroup/glTF-Asset-Generator) [ref:gltf-asset-generator], MIT [ref:gltf-asset-generator-license]: C# project generating importer conformance models (Accessor, Animation, Buffer, Material, Mesh, Node, Texture sampler, among others, and negative tests). Each test's README links a committed sample image per model [ref:gltf-asset-generator-sample-images]; whether those are reference renders is not stated.

## Sourcing strategy (approved by the owner, 2026-10-12)

1. **Tier 1, procedural and in-repo.** Analytic spheres, UV grids, normal-Texture patterns, instancing grids, seeded scatter, heightfields. No licence, deterministic, tiny. These are the CI-gated Golden and scale-ladder Reference scenes.
2. **Tier 2, small curated set.** `CC0-1.0` and `CC-BY-4.0` Khronos models, one or two CC0 HDRIs and PBR texture sets (Poly Haven, ambientCG), each with a manifest entry. Commit a file only when it is about 2 MB or less (`NormalTangentTest` qualifies); the roughly 10 MB PBR models are fetched like Tier 3, so clones stay light. Per-model size is checked in the ticket that adds it.
3. **Tier 3, large realism and stress scenes, fetched.** ORCA Bistro (after glTF conversion), IGN terrain tiles, and the roughly 10 MB PBR models. Pinned URL plus SHA-256, into a git-ignored cache; never committed. Used by local benches and milestone-exit visual checks. Intel Sponza stays unresolved: usable locally for experiments, never added to the manifest or redistributed until the package or Intel names the licence version.
4. **Manifest and hygiene.** One manifest records path, source URL, SPDX licence expression, credit text, upstream version, and SHA-256, for committed and fetched files alike. CI fails on an `assets/` file without an entry. Credits are collected in an attribution file. Files whose expression includes an `NC` term, or a restrictive `LicenseRef-` such as the CRYENGINE agreement, are marked dev-only. A `LicenseRef-LegalMark-*` term does not make a file dev-only: it forbids reusing the logo elsewhere, so the logo is replaced or kept out of shipped builds and marketing.
5. **Cleanup.** Remove unreferenced `pikuma.png`, `BoxTextured*`, and `CesiumLogoFlat.png` unless a test adopts them.
6. **Default test model.** Khronos `SciFiHelmet` (`CC0-1.0`, chosen by the owner on 2026-10-12, #37) replaces the non-commercial `DamagedHelmet.glb`, which is removed. One material, four 2048² images (base colour, metallic-roughness, normal, occlusion), so the loader takes it as is. About 30 MB [ref:scifihelmet-gltf-files] as `.gltf` plus `.bin` plus PNGs, so it is fetched (`praxis fetch`), never committed, and no CI Golden depends on it. `FlightHelmet` was not chosen: its three 1024² lens textures [ref:flighthelmet-lens-textures] fall back to the neutral layer. The second model, for later, is the Argus Camera (`CC0`, Virtual Museums of Małopolska on [Sketchfab](https://sketchfab.com/3d-models/argus-camera-f9112ea4c15043ebbb24fa121ffef920) [ref:sketchfab-argus-camera]): 110k faces, six 4096² maps [ref:sketchfab-argus-camera-textures] over two materials (amended 2026-10-26; four were listed), GLB 30.3 MB (not verifiable without a login). It waits for texture resizing and for re-hosting, since Sketchfab downloads need a login.
7. **Just in time.** Nothing is downloaded ahead of need. A ticket that needs an asset says what it needs (kind, licence class, size) and the owner supplies or approves the source at that point.
