How to read this page
  • Each point is one Bench record of main's source, from the bench-history branch (ADR 0024). Points are spaced by commit, not by date.
  • A Baseline record, imported from main's history. A record benched since. A tagged record, kept off the Series (a busy machine, another configuration), shown with the Tagged records switch. A tagged record off the chart's scale.
  • Shaded bands are Harness versions. A metric's definition can change from one to the next, so lines break between bands and no change is measured across them. A scene whose content changed breaks its line the same way.
  • Timing changes under 3% are left uncoloured. Counter changes are exact, so every one is marked.
  • Budgets are ADR 0013's, judged on the M4 Pro at 2560×1440. A dashed line is a machine with tagged records only.
