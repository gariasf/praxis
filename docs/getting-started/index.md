## Prerequisites

Before starting, ensure you have:

- **Rust** 1.70 or later
- **Vulkan SDK** installed and configured
- Basic familiarity with **Rust** or **systems programming**

## Installation Steps

1. **Install Rust** via [rustup](https://rustup.rs/)
2. **Install Vulkan SDK** from [LunarG](https://vulkan.lunarg.com/)
3. **Clone repository** and build:

```bash
git clone https://github.com/yourusername/praxis.git
cd praxis
cargo build
```

See [Installation](installation.md) for detailed instructions.
