# Game Engine Course

Welcome to the Praxis Game Engine Educational Course! This comprehensive curriculum teaches fundamental game engine concepts using multi-language code examples.

## Course Philosophy

This course is **engine-agnostic** and **language-agnostic**. We teach universal game engine patterns and algorithms that apply regardless of whether you're using Rust, C++, C#, or any other language.

### Multi-Language Learning

Every code example in this course is presented in **four formats**:

- **Pseudocode** 📝 - Abstract algorithm descriptions
- **Rust (Praxis)** 🦀 - ECS-based implementation with bevy_ecs
- **C++ (Unreal-style)** ⚙️ - Object-oriented implementation
- **C# (Unity-style)** 🎮 - Component-based implementation

Use the tabs to switch between languages and see how the same concept translates across different paradigms!

!!! tip "Language Preference Saved"
    Your language selection is automatically saved. All tabs across the site will sync to your preferred language.

!!! info "Keyboard Shortcuts"
    - ++alt+1++ : Switch to Pseudocode
    - ++alt+2++ : Switch to Rust
    - ++alt+3++ : Switch to C++
    - ++alt+4++ : Switch to C#

## Featured Topics

### Core Systems
- **Transform Hierarchy** - Scene graphs and spatial relationships
- **Rendering Pipeline** - Forward, deferred, and forward+ architectures
- **Physics Integration** - Fixed timestep and collision detection
- **Animation System** - Skeletal animation and blending
- **Asset Pipeline** - Loading, caching, and hot-reload

### Advanced Systems
- **Spatial Optimization** - Frustum culling, octrees, BVH
- **GPU-Driven Rendering** - Compute shaders and indirect draw
- **Networking** - Client-server, replication, lag compensation
- **Scripting** - Language integration and sandboxing
- **Editor Tools** - Undo/redo, gizmos, selection
