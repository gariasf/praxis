# Learning Paths

Structured progressions for mastering Praxis engine subsystems.

**Visual Guide**: See [Learning Paths Roadmap](roadmap.md) for visual progressions, role-based roadmaps, and project-specific recommendations.

**Glossary**: Check [Learning Paths Glossary](glossary.md) for definitions of terms used throughout the paths.

## Available Paths

Each path includes prerequisites, learning outcomes, and clear progression from beginner to advanced.

### Core Systems
- [**Rendering Path**](rendering.md) - Graphics pipeline mastery
- [**Animation Path**](animation.md) - Character animation techniques
- [**Physics Path**](physics.md) - Rigid body simulation
- [**Scripting Path**](scripting.md) - Lua integration
- [**Networking Path**](networking.md) - Multiplayer systems

### Supporting Systems
- [**Audio Path**](audio.md) - Sound and spatial audio
- [**Editor Path**](editor.md) - Editor tools and extensions
- [**Assets Path**](assets.md) - Asset pipeline and loading

## How to Use

1. **Choose your path** based on your goals
2. **Check prerequisites** before starting
3. **Follow the progression** (Beginner → Intermediate → Advanced)
4. **Run examples** for hands-on learning
5. **Complete exercises** to reinforce understanding
6. **Cross-reference** related systems
