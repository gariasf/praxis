## How Learning Paths Work

### Structure
Each path is divided into three levels:

<span class="difficulty-badge difficulty-beginner">Beginner</span>
Get started with the basics. No prior knowledge required.

<span class="difficulty-badge difficulty-intermediate">Intermediate</span>
Build on fundamentals with more complex topics.

<span class="difficulty-badge difficulty-advanced">Advanced</span>
Master advanced techniques and optimization.

### Components
Every level includes:

- 📖 **Theory** - Understand the concepts
- 💻 **Code** - See implementations in multiple languages
- 🎯 **Exercises** - Practice what you learned
- ✅ **Milestones** - Track your progress

### Time Commitment

| Level | Time Investment | Prerequisites |
|-------|----------------|---------------|
| Beginner | 1-2 weeks | None |
| Intermediate | 2-3 weeks | Completed beginner |
| Advanced | 1-2 weeks | Completed intermediate |

## Recommended Order

### First-Time Engine Developers
1. [Rendering Path](rendering.md) - Most visual feedback
2. [Physics Path](physics.md) - Shorter, good for momentum
3. [Animation Path](animation.md) - Builds on both
4. [Performance Path](performance.md) - Ties it together

### Experienced Programmers
Pick based on interest! Each path has clear prerequisites listed.

## Milestone Tracking

Track your progress through each path:

- [ ] Beginner: Complete core concepts
- [ ] Intermediate: Build working systems
- [ ] Advanced: Optimize and integrate

## Recommended Project Progressions

### Beginner Project
**Simple Scene Viewer**
- Load and display 3D models
- Basic camera controls
- Simple lighting

### Intermediate Project
**Interactive Demo**
- Player character with physics
- Multiple meshes with LOD
- Particle effects
- Basic UI

### Advanced Project
**Mini Game**
- Complete gameplay loop
- Optimized for 60 FPS
- Networked multiplayer (optional)
- Polish and effects

1. **Implement** the subsystem from scratch
2. **Explain** the theory and trade-offs
3. **Debug** common issues
4. **Optimize** for performance
5. **Integrate** with other systems
