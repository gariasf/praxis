# Components are pure data

Components hold data only: no closures, no `Box<dyn Trait>`, no behaviour methods. Behaviour lives in systems or, later, script handlers. A method that is a pure function of the component's own data and its arguments, with no side effect, closure or trait object, is not behaviour and is allowed: `Transform::to_affine`, `Bend::drawn_curvature` and `WorldTransform::{translation, drawn}` are of this kind (amended 2026-11-04, [#543](https://github.com/gariasf/praxis/issues/543)). Pure-data components serialise cleanly for save/load and let scripts hot-reload without dangling references inside ECS storage; every violation would have to be refactored before either ships.
