# Reference hardware and provisional budgets

Budgets are judged on an Apple M4 Pro until a Windows GPU machine exists; that machine gets its own ADR. Targets, provisional until the first baselines (accepted 2026-10-12): 60 fps at 1440p native with CPU at most 6 ms and GPU at most 12 ms per frame; 100k visible Instances, about 5M visible triangles, a 10 by 10 km streamed Game world, a 2 km LOD'd view distance, and GPU memory at most 8 GB at 1440p, counted as the bytes of the buffers and textures the engine has created, summed by the engine itself on every backend, because wgpu 29 has no allocator report on Metal; wgpu's allocator report and Metal's `currentAllocatedSize` are diagnostics only (unified memory has no separate VRAM pool; amended 2026-10-12, `docs/research/wgpu-capability-matrix.md`). A budget moves down freely and up only through an ADR or a map comment (`docs/agents/workflow.md`).
