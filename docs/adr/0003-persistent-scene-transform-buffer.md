# Persistent scene transform buffer

Transform-propagation results live in one GPU buffer indexed by renderable ID and are updated incrementally through dirty flags; there are no per-entity uniform buffers. GPU-driven rendering, ray-tracing TLAS rebuilds and instancing all consume exactly this shape. Implemented (#121): each Renderable keeps a slot in the Instance buffer until it stops being a Renderable, and a freed slot is taken again before the buffer grows; prepare writes only the slots of new Renderables and of those whose World transform or Material changed, found by bevy_ecs change detection, through the per-frame staging path, so camera motion writes no Instance. Refined by ADR 0014: the buffer stores an integer anchor plus an f32 offset per Renderable.
