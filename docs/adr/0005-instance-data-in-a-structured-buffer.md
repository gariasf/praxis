# Instance data in a structured buffer

Per-Instance data (model matrix, normal matrix, Material ID) sits in a structured buffer and each draw looks it up by `@builtin(instance_index)`; there is no bind group per mesh or per instance. Indirect and GPU-driven draws need exactly this lookup key. Implemented as the instance buffer in Phase 5 ([#12](https://github.com/gariasf/praxis/pull/12)). Refined by ADR 0014: the model matrix is relative to an integer anchor, which the Instance also carries. Since one draw spans every Instance (ADR 0019), the lookup key is the Instance slot in the Meshlet record a packed index names, not `@builtin(instance_index)` (amended 2026-10-20, [#194](https://github.com/gariasf/praxis/issues/194)).
