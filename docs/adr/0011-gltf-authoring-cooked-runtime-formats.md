# glTF for authoring, cooked binaries at runtime

glTF (from Blender) is the authoring source; the runtime loads cooked binaries with mip chains, GPU block compression (BC) and streaming-sized chunks. Loading glTF at runtime stays a development convenience; since #151 a development launch reaches glTF only through the cooker, which cooks what changed before the runtime loads Blobs (amended 2026-10-19, [#144](https://github.com/gariasf/praxis/issues/144)). Cooking is core engine work, not a late tool: it is the main memory lever (Textures are uncompressed RGBA8 without mips today) and it defines what streaming can load. Accepted 2026-10-12. Textures cook into KTX2, a standard container, and Asset identity, Cook keys and payloads are ADR 0018 (amended 2026-10-12, [#23](https://github.com/gariasf/praxis/issues/23)).
