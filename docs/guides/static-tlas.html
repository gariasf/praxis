The static TLAS

A TLAS over every static Instance, each in the entry of its slot and tagged with it, placed in a frame whose origin is the corner of the camera's Anchor in the first Frame data; built in that frame's upload and rebuilt only in a frame that writes or frees a static Instance, it is the first structure every shadow ray queries.

Describes main at fbae12f4 (2026-11-04). A change to the static TLAS rewrites this page and moves the commit; nothing is appended. Read first: A BLAS per Mesh for the structures its entries place, Instance Buffer Explained for the slots and writes it follows. The dynamic TLAS holds the Instances it leaves out; the shadow mask pass traces against both.

Interface

Runs
In every frame's Renderer::upload, after the loads' BLASes are compacted and before the dynamic TLAS's fill. It records a build in the first frame, and in a frame whose Instance writes change one of its entries.
Reads
The Frame data's instance_writes and the instances they cover; each static Instance's BLAS, from MeshPool::blas; the camera's Anchor, in the first Frame data only.
Writes
Its entries, one per slot up to STATIC_TLAS_CAPACITY; the Anchor of its frame, which the camera uniform carries to the GPU as tlas_anchor and the dynamic TLAS shares; the set of slots it leaves out.
Builds
One build_acceleration_structures of the TLAS alone, recorded into the frame's encoder ahead of the frame's copies and passes, in a frame that changes it.
Bind groups
Group 2 of the shadow mask pass, SHADOW_RAY_SCENE, as static_tlas, built once since the TLAS is rebuilt in place.
Shader
Queried in first_intersection, src/render/shaders/shadow_mask.wgsl.
Counted
static_instances_left_out in counters; its estimate at full capacity in estimated_acceleration_structure_bytes, and so in gpu_memory_bytes; its recording in the upload stage. No GPU pass time is taken of its build.

1 · Renderer::upload

Where it sits in the frame

The static TLAS is updated at the head of the frame's encoder, after the frame's loads have been built and compacted and before anything else the frame records, so the shadow mask pass later in the same command buffer reads it built.

// Loads staged since the last frame land before its copies and
// draws, and their BLASes are compacted before the static TLAS
// takes them.
self.load_staging.submit(&self.queue);
self.mesh_pool.compact_blases(&self.queue);
// Before the frame's encoder, as `prepare_encoder` says; it counts
// as the dynamic TLAS's recording.
let preparing = Instant::now();
self.dynamic_tlas.prepare_encoder(&self.device);
let prepare_time = recorder.stage(DYNAMIC_TLAS_RECORDING, preparing);
let mut encoder = create_frame_encoder(&self.device);
self.static_tlas
    .update(frame, &self.mesh_pool, &mut encoder);
recorder.counters.static_instances_left_out = self.static_tlas.instances_left_out();
// Shadow rays start in the static TLAS's frame, whose Anchor the
// first Frame data's camera set, and the dynamic TLAS shares it. Its
// fill counts as its recording, not as the upload.
let tlas_anchor = self.static_tlas.anchor();

Renderer::upload, src/render/renderer.rs; the dynamic TLAS's encoder and fill are the dynamic TLAS's.

Renderer::new creates it empty with STATIC_TLAS_CAPACITY slots. Each frame's upload first submits the loads staged since the last frame and, when they loaded Meshes, waits for their BLASes to be built and compacted (A BLAS per Mesh, Compaction); only then does StaticTlas::update take the frame's Instance writes and record a build into the new frame encoder, which render later fills with the frame's copies and passes and submits. The update also hands Frame stats the count of Instances it left out, and its Anchor goes into the camera uniform, which shadow rays start from.

2 · StaticTlas::update · tlas_instance

An entry per slot

An Instance's slot is its entry's index and its entry's tag. A static Instance whose Mesh has a BLAS fills its slot's entry; a Moving Instance, a freed slot and a Mesh no ray traces leave it empty.

/// The static TLAS (ADR 0020): each static Instance in its slot's entry,
/// tagged with its slot, in a frame whose origin is the corner of the
/// camera's Anchor in the first Frame data it takes, never re-anchored in M3.
/// It is built from that Frame data, empty or
/// not, so rays can always query it, and rebuilt in a frame that changes a
/// static Instance or frees one's slot.
pub struct StaticTlas {
    tlas: wgpu::Tlas,
    anchor: Option<[i32; 3]>,
    /// Slots past its capacity that hold a static Instance.
    left_out: HashSet<u32>,
}

impl StaticTlas {
    /// An empty static TLAS of `capacity` slots.
    pub fn new(device: &wgpu::Device, capacity: u32) -> Self {
        Self {
            tlas: device.create_tlas(&wgpu::CreateTlasDescriptor {
                label: Some("Static TLAS"),
                max_instances: capacity,
                // Rebuilt only when its Instances change, traced every frame.
                flags: wgpu::AccelerationStructureFlags::PREFER_FAST_TRACE,
                update_mode: wgpu::AccelerationStructureUpdateMode::Build,
            }),
            anchor: None,
            left_out: HashSet::new(),
        }
    }

StaticTlas and StaticTlas::new, src/render/acceleration_structures.rs.

/// Takes `frame`'s Instance writes, each static one's BLAS from
/// `mesh_pool`, and records its build into `encoder` for the first Frame
/// data and when they change a static Instance or free one's slot.
/// Returns whether it did.
pub fn update(
    &mut self,
    frame: &FrameData,
    mesh_pool: &MeshPool,
    encoder: &mut wgpu::CommandEncoder,
) -> bool {
    let mut changed = self.anchor.is_none();
    let anchor = *self.anchor.get_or_insert(frame.camera.anchor);
    let was_leaving_out = !self.left_out.is_empty();
    for write in &frame.instance_writes {
        let instances = &frame.instances[write.instances.clone()];
        for (slot, instance) in (write.first_slot..).zip(instances) {
            // A freed slot's Instance has no Mesh, so no BLAS.
            let blas = (!write.moving)
                .then(|| mesh_pool.blas(MeshHandle(instance.mesh)))
                .flatten();
            let Some(entry) = self.tlas.get_mut_single(slot as usize) else {
                if blas.is_some() {
                    self.left_out.insert(slot);
                } else {
                    self.left_out.remove(&slot);
                }
                continue;
            };
            *entry = match blas {
                Some(blas) => Some(tlas_instance(
                    blas,
                    anchored_transform(instance, anchor),
                    slot,
                )),
                None if entry.is_none() => continue,
                None => None,
            };
            changed = true;
        }
    }
    if !was_leaving_out && !self.left_out.is_empty() {
        tracing::warn!(
            left_out = self.left_out.len(),
            capacity = self.tlas.get().len(),
            "Static Instances left out of the static TLAS: their slots are past its capacity, so they cast no shadow"
        );
    }
    if changed {
        encoder.build_acceleration_structures(std::iter::empty(), std::iter::once(&self.tlas));
    }
    changed
}

StaticTlas::update, src/render/acceleration_structures.rs.

Prepare writes Instances in runs of consecutive slots, each run an InstanceWrite flagged moving where its Instances are Moving Instances, and splits a run where the flag changes. The update walks every written slot. A static Instance's entry gets its Mesh's BLAS; a Moving Instance gets none, so a static Instance that starts to move empties its entry the frame it does. A freed slot is written an Instance whose Mesh is NO_MESH, which has no BLAS, and a Mesh loaded MeshUse::Drawn has none either, so both empty the entry.

/// An Instance's entry in a TLAS: `blas`, placed by `transform`
/// (`anchored_transform`) and tagged with its `slot`.
fn tlas_instance(blas: &wgpu::Blas, transform: [f32; 12], slot: u32) -> wgpu::TlasInstance {
    // Every ray's cull mask.
    wgpu::TlasInstance::new(blas, transform, slot, 0xff)
}

tlas_instance, src/render/acceleration_structures.rs, which the dynamic TLAS's entries share.

Each entry is a wgpu::TlasInstance of the BLAS, a transform, custom data and a mask. The custom data is the slot, which a hit returns to the shader as instance_custom_data, so a hit can name the Instance it struck; the shadow mask pass's rays need only whether they hit, and read it nowhere. wgpu-core rejects custom data of 224 or more at build time, and every slot under the capacity fits. The mask is 0xff: a ray's 8-bit cull mask counts an entry only where the two share a bit, and the shadow rays pass 0xffu, so every ray sees every entry.

3 · anchored_transform

A frame anchored at load

An entry's transform is twelve f32, so the TLAS owns a frame of its own, as ADR 0014 requires of any subsystem that computes in f32: its origin is the corner of the camera's Anchor in the first Frame data it takes, and each entry's translation is composed from that corner in f64 and rounded to f32 once.

/// `instance`'s transform as rows of the 3×4 matrix a TLAS Instance holds,
/// its translation from `anchor`'s corner composed in f64, so only the f32
/// result rounds (ADR 0014).
fn anchored_transform(instance: &InstanceData, anchor: [i32; 3]) -> [f32; 12] {
    let [x_axis, y_axis, z_axis] = instance.rotation_scale;
    let row = |axis: usize| {
        let cells = i64::from(instance.anchor[axis]) - i64::from(anchor[axis]);
        let translation = cells as f64 * ANCHOR_CELL_SIZE + f64::from(instance.offset[axis]);
        [x_axis[axis], y_axis[axis], z_axis[axis], translation as f32]
    };
    bytemuck::cast([0, 1, 2].map(row))
}

anchored_transform, src/render/acceleration_structures.rs.

translation = (Instance Anchor − TLAS Anchor) × 64 m + Instance offset

The difference of the two Anchors is exact in integers, and the Instance's offset from its own cell's corner is under 64 m, so the only rounding that grows with distance is the final one, to f32, of the distance from the TLAS's origin. The rows come out as the 3×4 matrix [R | t], row-major, as wgpu takes them: each row is one axis's components of the rotation and scale columns, then that axis's translation.

The anchor is set by the first update and never moved, and StaticTlas::anchor returns it, zero before that update. The camera uniform carries it to the GPU as tlas_anchor; the shadow mask pass composes each ray's origin into this frame, and the dynamic TLAS places its entries in the same frame, so one ray is traced against both (the shadow mask pass, One ray).

ADR 0014's precision bar for a drawn point near the camera is 0.043 mm; its 100 km check renders every Reference scene that has a Golden shifted 100 km from the World origin, shadows included, and requires the Golden.

4 · changed

When it rebuilds

wgpu 30 cannot update a TLAS in place, so every change is a full rebuild, and the static TLAS rebuilds only in a frame that changes one of its entries: the first frame, a static Instance written, or a static Instance's entry emptied.

The first Frame data always builds it, even with no static Instance, since wgpu-core refuses a pass that uses a TLAS never built, and the shadow mask pass binds it from the first frame. Any write of a static Instance rebuilds, whether or not its data changed. The update returns whether it recorded a build.

5 · STATIC_TLAS_CAPACITY

Capacity and what it leaves out

The capacity is fixed at creation and every rebuild walks all of it, filled or not, so it is sized to the largest planned scene and no larger. Since entries are indexed by slot, it caps slot numbers: a static Instance in a slot past it casts no shadow, and is counted and warned about.

/// Slots the static TLAS covers: a static Instance in a higher slot is left
/// out, so it casts no shadow, and is counted and warned about. Sized for
/// the 250k Instances M3 plans `town` with, no larger: in wgpu a TLAS
/// rebuild's CPU time grows with its capacity, filled or not.
/// Provisional until ADR 0013's split of the 8 GB Budget sizes it.
pub const STATIC_TLAS_CAPACITY: u32 = 1 << 18;

STATIC_TLAS_CAPACITY, src/render/acceleration_structures.rs.

In wgpu 30 a TLAS holds one optional entry per slot of its capacity from its creation, and recording a build maps every one of them, filled or not, into what wgpu-core builds from; wgpu-core sizes the structure and its buffer of entries by capacity too. So 218 = 262,144 slots, sized for the 250,000 Instances town was planned with: its 254,256 Instances, as tests/frame_stats.rs counts them, its 10,000 Moving ones among them, all take slots below the capacity, with 7,888 to spare. Prepare takes a slot freed in an earlier frame before a fresh one, so slot numbers grow only when none is waiting.

A static Instance written to a slot past the capacity joins the left-out set, and a write with no BLAS to such a slot leaves it; Frame stats read the set's size as static_instances_left_out, shown on the counts line. The frame whose update takes the set from empty to holding one warns once, "Static Instances left out of the static TLAS: their slots are past its capacity, so they cast no shadow", with the count and the capacity; the next warning waits until the set has emptied and filled again.

6 · SHADOW_RAY_SCENE · first_intersection

What the rays read

The shadow mask pass binds the static TLAS once, since a rebuild writes it in place, and queries it first for every ray, before the dynamic TLAS.

/// Group 2 of the shadow mask pass, built once since its TLAS are rebuilt in
/// place: the static and dynamic TLAS it traces shadow rays against (ADR
/// 0020). No other pass binds them, but the dynamic TLAS's markers bind the
/// dynamic one: at submit, wgpu-core 30.0.1 walks a TLAS's dependencies, one
/// BLAS per Instance it holds, for each flush of a group holding it, at
/// least once per pass that binds one
/// [ref:wgpu-30-tlas-dependency-per-instance] [ref:wgpu-30-use-tlas-per-flush]
/// [ref:wgpu-30-submit-tlas-dependencies].
pub const SHADOW_RAY_SCENE: BindGroupDefinition = BindGroupDefinition {
    index: 2,
    label: "Shadow Ray Scene Bind Group",
    bindings: &[
        acceleration_structure("static_tlas", wgpu::ShaderStages::COMPUTE),
        acceleration_structure("dynamic_tlas", wgpu::ShaderStages::COMPUTE),
    ],
};

The head of first_intersection, src/render/shaders/shadow_mask.wgsl; the dynamic query after it is the shadow mask pass's.

Every BLAS's triangles are opaque and the ray forces opacity, so one rayQueryProceed completes the traversal and the committed intersection is the static TLAS's answer. A static hit settles a ray that asks for any hit; otherwise the dynamic TLAS is queried only up to the static hit. Where rays start, how far they go and what a hit means is the shadow mask pass's.

9 · ADRs 0013, 0014, 0016, 0020

Why this way

Two TLAS, split by motion. ADR 0020 splits the near field into a static TLAS, rebuilt only when its static Instances change, and a dynamic TLAS of Moving Instances, rebuilt each frame and capped at 10,000 Instances. One TLAS over everything would rebuild over every static Instance whenever anything moved, since wgpu-core 30.0.1 has no TLAS update, only rebuilds.

Indexed by slot. An Instance keeps its slot while it is one, so an entry needs no index of its own and a write names the entry it changes. The frame's shaders do not read it; a test's query reads it back to name the Instance a ray hit.

Anchored at load, never re-anchored. ADR 0014 forbids f32 World positions on the GPU and names ray-tracing acceleration structures among the subsystems that convert into a local frame they own; ADR 0020 anchors this one at scene load and never re-anchors it until Chunk streaming decides re-anchoring together with the TLAS's radius. Measured from that corner, a scene's entries round to f32 as near ones do, so the 100 km check holds for shadows.

A capacity sized to the plan. Every rebuild walks the full capacity, filled or not, so a larger one costs every static spawn in every scene; 218 holds town, provisional until ADR 0013's split of the 8 GB Budget sizes it.

A CPU wait before the build, at load. Nothing on the GPU orders the build after the compaction copies of the BLASes it reads, so compact_blases waits for them on the main thread, which alone submits and polls under ADR 0016. A wait once, at load, costs one frame; the per-frame refit, which could not pay that every frame, orders its writes on the GPU instead (the BLAS refit).

10

Limits

A CPU wait in each frame that loads Meshes. Before its update, the upload waits on the main thread for the GPU to build and then to compact the frame's new BLASes, since wgpu-core 30.0.1 records no barrier after a compaction copy on any backend and wgpu-hal 30.0.1 records none on Metal. A Mesh whose BLAS lost that race would cast no shadow until the next rebuild, which, where nothing static changes, never comes. Today every Mesh loads before the first frame, so the first frame alone waits; Meshes streamed during play would make every load frame wait, until a wgpu release orders the copy on every backend, a version change that is the owner's call.

A rebuild walks every slot. Spawning or despawning one static Instance costs a full rebuild at 218 slots, on the CPU in the frame that does it.

Slots past the capacity. A static Instance there casts no shadow, even when fewer than 218 Instances are static, since Moving Instances and freed slots hold slot numbers too.

Memory at full capacity. The estimate, and wgpu-core's allocation, are for every slot, so the smallest scene pays what town does.

One frame, fixed at load. The origin never moves, so an entry far from where the camera stood at load rounds to f32 more coarsely: from 2,048 m out its step is 0.244 mm.

A pinned wgpu. No update in place and no barrier after compaction are wgpu 30.0.1's; each holds while the pin does.

History

The static TLAS arrived on 2026-10-20, together with the BLAS per Mesh, anchored at load and rebuilt only when a static Instance changes; its first build in every scene, empty or not, came when the orrery, whose bodies all move, showed it could stay unbuilt. Shadow rays then came to read it, and the dynamic TLAS took the Moving Instances beside it.
